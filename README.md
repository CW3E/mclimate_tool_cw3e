## AR Impact Tool | GEFS Model Climate

---

This repository runs calculations and plots for the AR Hazard Tool. Plot types include IVT Model Climate (M-Climate), Freezing Level M-Climate, 1000-hPa wind M-Climate, QPF M-Climate, and the AR Hazard Index value for GEFS relative to GEFSv12 Reforecast M-Climate.

Current capabilities include the Southeast Alaska region for SEAK and NPAC domains.

### To run:

---

To run a specific domain with a singularity container:

```bash
## runs plots for GEFS for SEAK and NPAC domains
bash Run_GEFS_Mclimate.bash
```
